# ตู้เซฟพกพา (Portable Safe) โดย PetchPrize

โปรเจกต์นี้เกิดจากความขี้เกียจส่วนตัวของเป็ดไพร ที่ชอบพิมพ์รหัสผ่านใส่ไฟล์แล้วส่งเข้าอีเมลตัวเอง จะได้เปิดใช้ได้ง่ายๆ แต่มันอันตรายไง โดนแฮ็คทีนึงก็น่าจะไปทั้งยวง พอโดน AI บ่นจนหูชา เป็ดไพรก็เลยให้ Gemini ช่วยทำตู้เซฟพกพาขนาดจิ๋วในรูปแบบไฟล์ HTML ออฟไลน์ขึ้นมา เพื่อให้ชีวิตมนุษย์น้าง่ายขึ้นและปลอดภัยกว่าเดิม

## ตู้เซฟนี้ทำอะไรได้บ้าง
- ใช้ระบบเข้ารหัสระดับโลกอย่าง AES-256 แข็งแกร่งขนาดที่คอมพิวเตอร์ควอนตัมในอนาคตยังต้องนั่งสุ่มรหัสจนท้อ แปลว่าคุณจะสามารถ Save รหัสผ่านที่ต้องการซ่อนเอาไว้ลงไปได้เลย แล้วสามารถส่งไฟล์ที่เก็บรหัสผ่านนี้เข้าอีเมลตัวเอง หรือกระทั่งวางทิ้งไว้ในคอมได้เลย โดยไม่ต้องกลัวว่าจะมีคนมาเปิดดู เพราะต่อให้เปิดดู เขาก็จะดูไม่รู้เรื่อง และไม่เจอรหัสผ่านที่เราพิมพ์ไว้
- ทำงานแบบออฟไลน์ร้อยเปอร์เซ็นต์ ไม่มีการส่งข้อมูลส่วนตัวใดๆ ไปเซิร์ฟเวอร์หรืออินเทอร์เน็ตทั้งสิ้น
- เปิดใช้งานผ่านหน้าเว็บได้ทันที ไม่ต้องติดตั้งแอปพลิเคชันให้หนักเครื่อง

## วิธีใช้งานฉบับคนงงไอที
1. เข้าใช้งานผ่านลิงก์ GitHub Pages ของโปรเจกต์นี้
2. ตั้งรหัสผ่านหลัก (Master Password) ที่คุณจะไม่มีวันลืมเด็ดขาด
3. พิมพ์ชื่อเว็บไซต์และรหัสผ่านต่างๆ ที่ต้องการซ่อนลงในช่องข้อมูล
4. กดปุ่มเข้ารหัสเพื่อล็อกตู้เซฟ
5. ดาวน์โหลดหรือก๊อปปี้ไฟล์ที่เข้ารหัสแล้วไปเก็บไว้ในที่ปลอดภัย (เช่น ส่งเข้าอีเมลตัวเอง)
6. เวลาจะใช้งานก็เอาไฟล์นั้นมาวางในหน้านี้ (ในส่วนที่ 2 ถอดรหัสเพื่อเปิดดูข้อมูล) แล้วกรอกรหัสผ่านหลัก (Master Password) เพื่อถอดรหัสออกมาดู

## ข้อตกลงและคำเตือนสำคัญมาก
ไฟล์ตู้เซฟพกพานี้แจกให้ใช้งานฟรีตามสภาพที่เป็นอยู่ เป็ดไพรตรวจสอบความปลอดภัยในฝั่งโค้ดให้แล้วว่าโปร่งใส ไม่มีระบบดักจับข้อมูลแอบแฝงใดๆ ทั้งสิ้น

เนื่องจากระบบนี้เป็นแบบออฟไลน์แท้ๆ ข้อมูลทั้งหมดจะถูกเข้ารหัสและอยู่ภายใต้การดูแลของผู้ใช้เท่านั้น หากเกิดเหตุการณ์ลืมรหัสผ่านหลัก คอมพัง ไฟล์หาย หรือข้อมูลสูญหายขึ้นมา เป็ดไพรจะไม่สามารถกู้ข้อมูลคืนให้ได้ และไม่ขอรับผิดชอบต่อความเสียหายใดๆ ในทุกกรณี ผู้ใช้งานต้องยอมรับความเสี่ยงด้วยตัวเองทั้งหมด

ถ้าเกิดลืมรหัสผ่านหลักขึ้นมาคือจบตรงนั้นทันที เทพองค์ไหนก็ช่วยกู้กลับมาให้ไม่ได้ ดังนั้น โปรดใช้งานด้วยความระมัดระวังและโปรดพึ่งพาความจำของคุณเอง
