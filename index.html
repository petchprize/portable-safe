🔒 ตู้เซฟข้อความพกพา (Secure Text Vault)

ไฟล์นี้ทำงานแบบออฟไลน์ 100% บนเครื่องของคุณ (ปลอดภัย ไม่ส่งข้อมูลไปที่ไหน)
ใช้สำหรับเข้ารหัสข้อความ/รหัสผ่านเป็นไฟล์ล็อก หรือถอดรหัสเพื่อเปิดดู เพื่อแนบเข้า Email ได้อย่างปลอดภัย

➕ 1. บันทึกและเข้ารหัสข้อมูลใหม่
🔓 2. ถอดรหัสเพื่อเปิดดูข้อมูล
เข้ารหัสด้วยอัลกอริทึม Web Crypto API (AES-GCM 256-bit) มาตรฐานความปลอดภัยสูง | พัฒนาขึ้นเพื่อใช้งานแบบพกพา
